# Projeto React Router

## Apresentação

Projeto desenvolvido durante os estudos da Geração Tech 4.0
para praticar configuração de rotas e navegação entre páginas
utilizando React Router.

## Funcionalidades

- Navegação entre páginas.
- Componentes compartilhados de layout.
- Carregamento de páginas com lazy loading.
- Parâmetros dinâmicos na URL.
- Página 404 para rotas inválidas.

## Tecnologias utilizadas

- React
- JavaScript
- React Router DOM
- Vite
- CSS
